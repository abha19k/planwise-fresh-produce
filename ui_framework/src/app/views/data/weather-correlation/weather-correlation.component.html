How to Interpret Feature Importance
Importance shows model reliance, not causal impact.
A feature with high importance was useful to the XGBoost model when making predictions. It does not mean that the feature causes the same percentage change in demand or forecast accuracy.
Use Factor Contribution to determine whether weather or promotions actually improve historical forecast accuracy. Feature Importance answers a different question: which variables does the trained forecasting model rely on when making predictions?
